# Terminal Portfolio

Página en React (Vite) con fondo animado tipo consola, sidebar de navegación y
layout en columnas. Lista para subir a GitHub Pages.

## Uso local

```bash
npm install
npm run dev
```

## Deploy a GitHub Pages

1. Cambiá `base: '/nombre-del-repo/'` en `vite.config.js` por el nombre real de tu repo.
2. `npm run deploy`
3. Activá GitHub Pages en Settings → Pages → rama `gh-pages`.

Ver la guía en PDF adjunta para el paso a paso completo.
